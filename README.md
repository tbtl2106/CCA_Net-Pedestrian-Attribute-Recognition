# CCA_Net-Pedestrian-Attribute-Recognition
PyTorch-based pedestrian attribute recognition for UPAR2027. Features CCA_Net with SigLIP2 and attribute self-attention, DINOv3 image encoders, and ROI Mixture-of-Experts. Supports multi-label training, evaluation, and Docker workflows. The submitted CCA_Net achieved 75.01% Challenge Average on the hidden test set.
